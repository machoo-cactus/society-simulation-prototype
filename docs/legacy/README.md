# Legacy documentation

This directory contains historical records, not current instructions.

## Contents

- `requirements/`: original product requirements retained as the baseline that
  motivated Stage 0.
- `plans/`: completed or superseded implementation and architecture plans.
- `assessments/`: dated project assessments that describe an earlier state.
- `prompts/`: archived scratch prompts and idea notes.

Historical documents may mention removed JavaScript modules, canvas rendering,
old URLs, Windows-first commands, or architecture that has since changed. Do
not update those descriptions to look current; their value is provenance.

Current guidance is indexed in `docs/README.md`.
