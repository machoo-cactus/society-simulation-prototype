Document Status: Draft / Conceptual Baseline
Target Stage: Stage 0 Experimental Prototype
Primary Focus: Core Agent Primitives, Dual-Clock Mechanics & Spatial Grounding
1. Executive Summary & Architectural Philosophy
The goal of the broader simulation platform is to enable large-scale, multi-agent human simulations using Dynamic Fidelity through Lazy State Materialization. However, before deploying dynamic statistical probability fields (Tier 2) or state reification operators ($\mathcal{R}$), the underlying ground-truth cognition and environment mechanics must be proven in isolation.
This document defines the requirements for the Stage 0 Prototype. This simplified sandbox eliminates all statistical fabrication and state materialization/collapse mechanisms. Instead, every agent operates as a fully materialized entity within a deterministic $2D$ spatial grid.
The primary objective of Stage 0 is to validate the core agent primitives—continuous physiological homeostasis, System 1/2 arbitration, spatial affordances, and vector-backed memory—and to serve as the ground-truth data collection bed for building statistical priors in future iterations.

3. Core Functional Requirements & Agent Primitives
3.1 Primitive A: Continuous Homeostatic Core (Biological ODEs)
Requirement: Agents must possess an internal biological state represented by continuous somatic variables $\vec{h}(t) = [\text{Hunger}, \text{Energy}, \text{Stress}]$.
Behavior:
Somatic meters decay or accumulate continuously on every micro-tick sub-step ($dt = 1\text{s}$) according to deterministic ordinary differential equations (ODEs):
$$\frac{d\vec{h}}{dt} = -\mathbf{\Lambda} \vec{h}(t) + \mathbf{B} \vec{u}_{\text{activity}}(t)$$
Decay calculations must execute at zero LLM token cost.
Specific activities (e.g., WORKING) accelerate fatigue and stress accumulation, while resting or eating recovers states.
3.2 Primitive B: Dual-Process Action Arbitrator (System 1 vs. System 2)
Requirement: Agent decision-making must be split into unconscious survival drives (System 1) and conscious goal planning (System 2).
Behavior:
System 2 (Deliberative Planning): Operates when all somatic meters exceed defined critical thresholds ($\vec{h}(t) > \vec{\theta}_{\text{critical}}$). The agent executes high-level daily routines generated by an LLM (e.g., working, socializing, reading).
System 1 (Instinctive Survival Interrupt): Executes automatically when any somatic variable breaches its critical threshold ($h_i(t) \le \theta_{i, \text{critical}}$).
Priority Invariant: System 1 acts as a non-bypassable hardware interrupt. It immediately clears the System 2 plan queue and locks the agent's pathfinding directly to the nearest corrective spatial affordance (e.g., Fridge for hunger, Bed for exhaustion) without requiring LLM validation.
3.3 Primitive C: Spatial Topology & Affordance Engine
Requirement: The simulation environment must provide physical structure and interactable objects.
Behavior:
Map layout consists of a 2D discrete coordinate grid ($N \times M$) categorized into functional zones (Kitchen, Bedroom, Office, Lounge).
Movement along the grid uses deterministic pathfinding ($A^*$ algorithm) with collision awareness.
Interactive stations expose deterministic Affordances. When an agent occupies an affordance tile, it can execute associated actions that alter its homeostatic meters directly (e.g., EAT $\to \text{Hunger} + 60$).
3.4 Primitive D: Associative Memory & Context Retrieval
Requirement: Agents must maintain episodic context that can be dynamically queried based on semantic relevance.
Behavior:
Observations, social dialogues, and major biological events are committed to a vector-indexed episodic memory buffer.
Prompt generation for dialogue or social reflection queries this buffer, retrieving top-$k$ relevant memories using vector similarity combined with temporal recency weighting.
3.5 Primitive E: Real-Time Visual Telemetry Interface
Requirement: System behavior must be observable in real time via a web interface.
Behavior:
Render a 2D canvas displaying agent coordinates, movement vectors, and zone boundaries.
Provide live telemetry bars displaying active somatic meters ($\text{Hunger}, \text{Energy}, \text{Stress}$) for selected agents.
Stream an event log detailing active agent plans, System 1 interrupts, and generated LLM dialogue turns.
4. System Invariants & Non-Negotiable Rules
Zero-Token Physical Decay: Movement across coordinates and metabolic decay must never invoke an LLM call.
Absolute System 1 Preemption: An agent experiencing critical hunger ($\le 15\%$) cannot be overridden by an LLM prompt instructing it to stay at its desk. Biological survival unconditionally overrides social or narrative duties.
Deterministic Action Outcome: Action execution at affordance stations must succeed or fail based on explicit world state variables, not natural language interpretation.
5. Future Scope & Integration Roadmap
This prototype explicitly excludes multi-fidelity execution mechanisms. Its primary long-term architectural purpose is to act as the baseline ground truth required to build those mechanisms.

Out-of-Scope for Stage 0 (Deferred to Future Stages):
Tier 2 Statistical Background Fields: No agent will exist as a pure probability distribution in this stage.
State Reification Operator ($\mathcal{R}$): No Just-In-Time (JIT) materialization or backward history imputation will be performed; all agents exist continuously.
State Collapse Operator ($\mathcal{C}$): No agents will be dematerialized into delta vectors or parametric updates during execution.
Distributed Compute Scaling: The prototype runs within a single process; Ray distributed cluster orchestration is excluded.
How Stage 0 Enables Future Stages:
Data Collection Engine: Uninterrupted full-simulation runs of Stage 0 will generate dense log files of spatial trajectories, homeostatic decay curves, and schedule transition frequencies.
Prior Calibration: These dense logs will be mined offline to construct the parametric Gaussian distributions and Markov transition matrices required for Tier 2 Statistical Background Fields.
Causal Benchmark: Stage 0 provides the "ground truth" simulation baseline against which future multi-fidelity runs (Tier 0/1/2 hybrid) will be benchmarked for causal fidelity and token savings.
